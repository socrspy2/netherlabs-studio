# Vector Studio

# 🧪 Netherlabs Studio App

Vector Studio is an open-source design tool we’re building as a practical alternative to tools like Figma, Adobe XD, and Framer, with a strong focus on exporting things you can actually use in real projects.

The goal is to design visually and then export either assets or real code without being forced into one workflow.

# What is Vector Studio? 

Vector Studio is a visual editor where you can design UI the same way you would in modern design tools, but with more freedom in how you ship the result.

You can export designs as images like PNG or JPG, but also as sandbox snippets or full React components. Some people might only use it to design reusable components, others might build entire layouts or full websites. Both are valid.

You decide how far you take it.

# Features (planned and in progress) 

Vector based editing with frames, layers, and reusable components.
Animations and transitions similar to what you’d expect from tools like Framer.
Exports to images, sandbox snippets, and React components.
Support for building both single components and full website layouts.

This is an active project and things will change as we build and test new ideas.

# Open source and free forever!!!

Netherlabs is an open-source startup and Vector Studio is free to use forever.

No paywalls.
No locked exports.
No paid features required to build or export anything.

All core functionality stays available to everyone.

Payments (optional, non-blocking) 💎

We don’t plan to sell features.

Any payments in the future will be for cosmetics and themes only, and they won’t affect Vector Studio itself. These cosmetics are tied to user profiles inside the Netherlabs Central Hub, not the editor.

If you never touch cosmetics or the hub, Vector Studio still works fully.

# Netherlabs Central Hub 

Vector Studio is part of a bigger ecosystem we’re building called Netherlabs Central Hub, but it’s completely optional.

The hub is meant to be a social and creative space where users can chat, build a personal visual space (Sims-like but online), share themes, create and sell plugins, and showcase work.

Vector Studio stays standalone and usable on its own.
